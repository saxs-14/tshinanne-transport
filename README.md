# Tshinanne Transport 🚛

A mobile-first fleet and business management system for Tshinanne Transport, a local sand-delivery business operating around Thohoyandou, Limpopo.

## MVP

- Owner dashboard
- Two TATA 1518 tipper trucks
- Driver management
- Sand delivery/order tracking
- Customer records
- Income and expense tracking
- Fuel records
- Maintenance records
- Truck profitability
- Owner/driver role separation

## Planned stack

- React + TypeScript
- Vite
- Tailwind CSS
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Progressive Web App (PWA)

## Development principle

The first release is designed to be usable with little or no operating cost by relying on free-tier services and the driver's/owner's existing phones. Dedicated GPS hardware and paid integrations are intentionally deferred.
